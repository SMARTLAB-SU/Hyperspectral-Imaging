# App / exe

This folder contains the compiled executable files for the Hyperspectral Imaging System.

Due to file size, the executables are hosted externally on Google Drive instead of being committed directly to this repository.

## Files

### 1. HyperspectralImaging.exe
- **Description:** Main application executable. Run this directly to launch the Hyperspectral Imaging System without installation.
- **Download:** [Download HyperspectralImaging.exe (Google Drive)](https://drive.google.com/file/d/1HoCol66_ExuojPXvfUXJMjDM9vCpZ0zL/view?usp=drive_link)

### 2. HyperspectralImaging_setup.exe
- **Description:** Installer package built using Inno Setup. Installs the application on your system with a standard setup wizard (creates shortcuts, uninstaller, etc.).
- **Download:** [Download HyperspectralImaging_setup.exe (Google Drive)](https://drive.google.com/file/d/1HoCol66_ExuojPXvfUXJMjDM9vCpZ0zL/view?usp=drive_link)

## How to Use

**Option 1: Run directly**
1. Download HyperspectralImaging.exe
2. Double-click to run — no installation required

**Option 2: Install via setup**
1. Download HyperspectralImaging_setup.exe
2. Run the installer and follow the on-screen instructions
3. Launch the app from the Start Menu / Desktop shortcut created during installation

## System Requirements
- OS: Windows 10/11 (64-bit)
- RAM: 8 GB recommended
- Display: 1280x720 or higher resolution

## Notes
- If Windows SmartScreen shows a warning, click More info → Run anyway (this is expected for unsigned executables).
- For source code, see the `Source_Code/` folder in this repository.
- The installer script (.iss) used to build the setup file is available in the `ISS/` folder.
