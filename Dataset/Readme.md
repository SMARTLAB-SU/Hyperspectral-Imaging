# Hyperspectral & Plant Disease Datasets

This directory contains metadata, specifications, and direct access links to the Kaggle datasets used in this project.

## 📊 Clickable Kaggle Dataset Links

1. 🌿 **[Plant Disease Detection Kaggle Dataset](https://www.kaggle.com/datasets/vedikapangavhane/plant-disease-detection-kaggle?select=valid)**
   - Contains validation and training datasets for plant disease detection.

2. ⚖️ **[Balanced Dataset](https://www.kaggle.com/datasets/vedikapangavhane/balanced-dataset)**
   - Class-balanced dataset optimized for model training and evaluation.

3. ✂️ **[Splitted Dataset](https://www.kaggle.com/datasets/vedikapangavhane/splitted-dataset)**
   - Pre-split train, validation, and testing dataset sets.
